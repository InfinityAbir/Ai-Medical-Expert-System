# 🧠 AI Medical Expert System

A hybrid AI-based expert system for medical diagnosis that integrates multiple artificial intelligence techniques including rule-based reasoning, Bayesian inference, search algorithms, and machine learning.

---

## 🚀 Features

- ✅ Rule-Based Knowledge System
- ✅ Bayesian Probabilistic Reasoning
- ✅ Best-First Search Algorithm
- ✅ Machine Learning Models (Decision Tree, Naive Bayes)
- ✅ Large Synthetic Dataset (~900 samples)
- ✅ Performance Evaluation (Accuracy, Precision, Recall, F1 Score)
- ✅ Confusion Matrix & Visualization
- ✅ Model Comparison

---

## 🧩 Technologies Used

- Python
- Pandas
- Scikit-learn
- Matplotlib

---

## 📊 System Workflow

1. User inputs symptoms
2. Rule-based system calculates matching scores
3. Bayesian model computes probabilities
4. Search algorithm ranks diseases
5. Machine learning predicts final diagnosis
6. Results displayed with confidence scores

---

## ▶️ How to Run

### 1. Install dependencies
    pip install pandas scikit-learn matplotlib
    pip install matplotlib
    pip install pandas scikit-learn numpy  

### 2. Run the system
    python main.py
